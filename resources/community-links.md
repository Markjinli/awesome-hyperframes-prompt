## 学习路径推荐

### 零基础 → 第一个视频（~2 小时）

1. 看 [hyperframes-student-kit](https://github.com/nateherkai/hyperframes-student-kit) 的 README（15 分钟）
2. 选本项目的一个初级模板（⭐⭐），复制 prompt.md 修改（10 分钟）
3. 用 Claude Code / Cursor 生成 HTML（30 分钟）
4. `npx hyperframes preview` 预览 + 迭代（45 分钟）
5. `npx hyperframes render` 导出（15 分钟）

### 进阶 → 批量生产（~1 天）

1. 研究 [vibe-video](https://github.com/agno-agi/vibe-video) 的自动化管线
2. 参考 [hyperframes-fix](https://github.com/liangdabiao/hyperframes-fix) 做本地化
3. 建立自己的「风格库」——把满意的 HTML 片段归档
4. 写一个 script 批量生成同类视频
