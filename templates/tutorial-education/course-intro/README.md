# Course Intro — Mastering React 2026

> 20-second course introduction video. Code editor aesthetic with dark navy + electric blue. Four scenes: hook question, curriculum grid, instructor intro, and enrollment CTA.

---

## Use Cases

- Online course landing page hero videos
- YouTube course trailers and channel promos
- EdTech platform course previews
- Bootcamp or workshop registration ads
- Developer tool or library launch announcements

---

## Key Techniques

| Technique | Where | Why |
|-----------|-------|-----|
| **Staggered word reveal** | Scene 1 hook question | Words scale in with `back.out(1.5)` — punchy typewriter energy that grabs developer attention |
| **CSS Grid curriculum cards** | Scene 2 course overview | 3x2 card grid with staggered `translateY` entrance — comprehensive "everything included" feel |
| **Instructor trust building** | Scene 3 | Photo with pulse ring + pill badges (years, talks, students) stagger in — credibility through social proof |
| **Glow pulse CTA button** | Scene 4 | `@keyframes` box-shadow pulse keeps the CTA breathing without being aggressive |
| **Decorative code editor** | Scene 1 background | IDE mockup with syntax-highlighted code (Fira Code) — reinforces the developer-course identity |
| **Grid overlay** | Global | 60px CSS grid with `linear-gradient` lines — subtle code-editor texture |

---

## Customization

1. Replace `"Mastering React 2026"` with your course name throughout
2. Swap the 6 module cards in Scene 2 with your actual curriculum
3. Update instructor name, title, and stats (`"Sarah Kim"` -> your instructor)
4. Change CTA text `"Enroll Now — Early Bird Pricing"` and URL `react2026.dev`
5. Adjust colors: `#1E293B` (bg), `#3B82F6` (accent), `#F59E0B` (highlight) -> your brand
6. Replace the hook question to match your target audience's pain point
