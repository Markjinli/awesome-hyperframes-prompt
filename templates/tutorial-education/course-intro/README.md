# Course Intro — 在线课程介绍

## 效果

20 秒的在线课程介绍视频。"Mastering React 2026" 课程推广，含代码编辑风视觉、课程大纲预览、讲师卡片。

## 适用场景

- 在线课程/训练营推广
- YouTube 教程系列片头
- 技术 Workshop 宣传

## 关键技巧

- **代码编辑风**：深色 `#1E293B` 背景 + JetBrains Mono 代码字体
- **课程大纲**：grid 布局展示 3-4 个核心模块
- **讲师卡片**：带照片 + 简介的卡片组件

## 自定义方法

1. 替换课程名和讲师信息
2. 修改课程模块内容
3. 调整配色：`#3B82F6` → 你的品牌色
