# Grain Film Look — 胶片质感美学

> 模拟 16mm/35mm 胶片质感：颗粒纹理、宽银幕遮幅、对焦呼吸、色彩偏移、暖调光晕。给你的视频赋予「电影感」。

## 效果

15-25 秒的胶片质感品牌视频。宽银幕 2.35:1 遮幅、持续滚动的胶片颗粒、文字从模糊中「对焦」浮现、暖调色彩偏移。适合品牌故事、高端产品发布、创意短片。

## 适用场景

- 奢侈品/高端品牌宣传
- 品牌起源/创始人故事
- 时尚/美妆/生活方式品牌
- 创意工作室作品集

## 胶片质感层
在全片叠加以下效果，全程持续：

**颗粒纹理**
- SVG feTurbulence 生成胶片颗粒
- opacity：0.15（微妙，不喧宾夺主）
- 每帧随机种子变化，模拟真实胶片的随机颗粒分布
- 使用 seed 随时间微调（不用 Math.random()）

**宽银幕遮幅（Letterbox）**
- 上下黑色遮幅，模拟 2.35:1 宽银幕比例
- 上边：1080 * 0.13 = 140px 黑条
- 下边：1080 * 0.13 = 140px 黑条
- 遮幅以微小动画入场（上下黑条从中央向外展开，像电影开场）

**色彩偏移（Color Shift）**
- 全局 color-adjust：暖色 +5%，绿色 -2%
- 高光区域（>80% brightness）：微弱的黄色偏移
- 阴影区域：微弱的青色偏移（模拟胶片暗部冷调）
- 使用 CSS filter 或 SVG color matrix

**对焦呼吸（Focus Breathe）**
- 场景切换时：新场景 blur(12px) → blur(0)，0.8s
- 模拟镜头对焦的过程
- 不是每个场景都加——只在情感转折点使用

## 场景内容

**场景 1（0-6s）— 标题浮现**
- 暗色背景下，品牌名从完全模糊中「对焦」浮现
- blur(30px) → blur(0)，sine.inOut，1.5s
- 字体：优雅衬线体（Playfair Display / Cormorant Garamond）
- 字号：96px，颜色：暖白 #F5F0EB
- 文字出现后，微弱的暖金色光晕在文字后方扩散
- 颗粒和遮幅在 0.5s 内同时淡入

**场景 2（6-14s）— 品牌叙述**
- 场景渐变为温暖的抽象背景（渐变 + 柔焦光斑）
- 两段品牌文案依次浮现：
  1. "[品牌理念/使命第一句]"
  2. "[品牌理念/使命第二句]"
- 每次浮现：blur(8px) + opacity(0) → blur(0) + opacity(1)
- 字体：衬线体 Regular，字号 48px
- 行间距：1.6（宽松，优雅）
- 颜色：温暖的象牙白 #FFF8F0
- 每段停留 3s，给观众足够时间阅读

**场景 3（14-20s）— 结束**
- 所有文字淡出
- 遮幅从外向内闭合（缓慢的黑条推进）
- 颗粒继续到最后 0.5s，然后也淡出
- 中央留下一行小字 URL：[brand.com]
- 最后 1s：完全黑屏，只留颗粒在黑暗中闪烁

## 关键技巧

- **24fps 是灵魂**：30fps 是视频/电视感，24fps 是电影感。这个区别观众能感觉到但说不出来
- **颗粒不是脏**：opacity 0.12-0.18 刚好。低于 0.10 看不见，高于 0.25 像脏画面
- **对焦入场 > Fade 入场**：blur(30px) → blur(0) 比单纯的 opacity fade 更有「镜头对焦」的叙事暗示
- **遮幅制造电影感**：上下黑条是告诉观众的潜意识信号——「这是电影，不是广告」
- **色彩偏移是隐形的**：观众不会注意到 +5% 暖色和 -2% 绿色，但整体氛围会感觉「温暖的胶片」

## 自定义方法

1. 替换品牌名和文案
2. 调整颗粒 opacity（更粗 = 0.2，更细 = 0.1）
3. 切换衣银幕比例：1.85:1（遮幅更窄）或 1.33:1（经典 4:3）
4. 修改色彩偏移方向：暖调→冷调，金黄→银蓝
5. 更换字体为你的品牌字体
